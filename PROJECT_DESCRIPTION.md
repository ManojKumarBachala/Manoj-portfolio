# Manoj Kumar Bachala - Portfolio Website

This responsive portfolio website presents Manoj Kumar Bachala as a full-stack developer. It highlights his technical skills in front-end and back-end development, along with selected academic projects in cybersecurity, language conversion, and e-commerce. The website uses semantic HTML and custom CSS for a clear layout, responsive sections, interactive navigation, and accessible focus states. It is designed to work smoothly across desktop and mobile screens without JavaScript or external frameworks.
