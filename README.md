# Manoj Kumar Bachala — Portfolio

A responsive developer portfolio built with plain HTML and CSS. No package installation, build step, or JavaScript runtime is required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

Alternatively, run a local server from this folder:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

The page uses `style.css` from the same folder. Google Fonts are optional; system font fallbacks are included.

## Project files

- `index.html` — portfolio page
- `style.css` — layout, styling, and responsive rules
- `PROJECT_DESCRIPTION.md` — project overview
- `HTML_CSS_Internship_Project_Guide.pdf` — project guide
- `screenshots/` — reserved for project screenshots
